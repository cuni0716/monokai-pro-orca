# Monokai Pro (Community Edition) for [Orca](https://www.onorca.dev)

## Installation instructions

Install the plugin from its Git URL:

1. In Orca, open **Settings → Plugins → Install → Git URL**.
2. Paste `https://github.com/cuni0716/monokai-pro-orca` and install.

Or clone it from GitHub and install it as a local folder (**Settings → Plugins → Install → Local folder**):

```zsh
git clone https://github.com/cuni0716/monokai-pro-orca.git
```

### Activating theme

1. Enable the **Monokai Pro (CE)** plugin in **Settings → Plugins**.
2. In **Settings → Appearance**, choose **Monokai Pro (CE)** as the dark theme and as the terminal theme.
3. Enjoy!
